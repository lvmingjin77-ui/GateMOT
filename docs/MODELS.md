# Checkpoints

## Coming soon

GateMOT checkpoints for BEE24, SportsMOT, MOT17, and MOT20 will be linked here. Each model will include its training split, selected epoch, configuration, and evaluation command. Checkpoint downloads are not available yet.

The [README](../README.md#results) lists the manuscript results. You can already [train and evaluate your own models](../README.md#training) using the provided scripts. The example `model_last.pth` files are generated by training, not downloaded from this page.

The main models use the complete training split of each dataset. SportsMOT Table 2 uses epoch 70 of its 80-epoch schedule. A half-training checkpoint is a separate development model and cannot replace a full-training checkpoint for the reported test result.

## Backbone initialization

The ImageNet initialization weights are available from the DLA project. Download them into `pretrain/` without renaming:

| Backbone | Used by | Download |
|---|---|---|
| DLA-34 | BEE24, MOT17, MOT20 | [dla34-ba72cf86.pth](http://dl.yf.io/dla/models/imagenet/dla34-ba72cf86.pth) |
| DLA-60 | SportsMOT | [dla60-24839fc4.pth](http://dl.yf.io/dla/models/imagenet/dla60-24839fc4.pth) |

Inference with a complete GateMOT checkpoint does not require separate ImageNet weights.
